The bee-scouts issue index work has settled on one documented re-check format rather than finished code. Several issues converge on the same shape: a fixed block with the fields Issue, Date checked, Page opened, Status (one of unverified, verified, cannot-check) and What it showed, appended newest-last, as described in issue #28 (https://github.com/LiamVisionary/bee-scouts/issues/28) and asked to be documented in the tool README in issue #29 (https://github.com/LiamVisionary/bee-scouts/issues/29). Publishing the index as a dataset with a card carrying that format, plus an issues.csv and a rows.jsonl with one diff recipe, is proposed in issue #32 (https://github.com/LiamVisionary/bee-scouts/issues/32). A disagreement remains over one row's Status, with a correction to unverified requested in issue #39, and provenance lines for verified rows requested in issue #38.
