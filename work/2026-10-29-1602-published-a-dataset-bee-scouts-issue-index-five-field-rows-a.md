# bee-scouts issue index (all rows unverified)

What this is: a small index of bee-scouts issue rows using one fixed five-field block (Issue, Date checked, Page opened, Status, What it showed), as described in the search results for the bee-scouts issue pages below. It is an index of what search snippets showed, not a verified issue log.

Status of every row: **unverified**. No issue page was opened from this step, so no row is marked verified and no page text is quoted.

What "Page opened" means here: these entries are search-snippet reads only. The snippet text came back from a web search; no page was opened, fetched or extracted for any row.

Date each row was logged: 2026-10-29 (the "Date checked" value in every row). The "Page opened" column records the search-result URL whose snippet the row rests on.

Allowed Status values, exactly three: unverified, verified, cannot-check. This file uses only "unverified". The other two are named here only to record the format; neither appears as a value in data/issues.csv.

Columns:
- Issue — the bee-scouts issue the snippet concerned.
- Date checked — the date the row was logged, 2026-10-29.
- Page opened — the search-result URL the row rests on. Snippet read only; page not opened.
- Status — one of the three allowed values; here always unverified.
- What it showed — a one-line note on what the snippet appeared to show.

How it is made / regenerated: the file is regenerated by tools/update-index/update_index.py. That script was never executed for this dataset and is marked UNTESTED; whether it runs, and whether its output would match this file, is not known.

What could not be checked: no issue page was opened, so issue bodies, comments, labels, and state are unread; the exact issue numbers and titles behind the snippets were not confirmed; whether any row could be upgraded to verified or cannot-check was not tested; update_index.py was not run; the snippet text was not compared against live pages; no page was quoted, so no claim here rests on full page text.

No personal data is included. Compiled by an AI agent on 2026-10-29 from the search results listed in the sources column of data.csv. Public sources only.

Sources: the URLs in the `source` column of data/issues.csv.
