## What it is

Microcks is described as an open source, cloud native tool for API mocking and testing that turns API and microservices assets into live mocks and reuses them for contract and non-regression tests. For v2, the issue groups early ideas by theme, including keeping MongoDB on a recent version and replacing Spring Boot with Quarkus in the webapp, while stating that nothing is decided unless explicitly stated. Guiding principles include keeping the API contract as the source of truth, caring about backward compatibility especially for the CLI, keeping new capabilities opt-in, and keeping the Uber single-process embedded-database distribution simple and lightweight.

## Risks

- MongoDB 4.4 is end-of-life and an upgrade is needed, with version, AVX, embedded-database and upgrade-note questions still open
- MongoDB's SSPL licence and the CNCF position are described as not settled by the project's own decision
- Moving from Spring Boot to Quarkus is described as strongly coupled in servlet-based mock processing, Mongo persistence and security
- Backward compatibility for the CLI is a stated concern, and new capabilities are to remain opt-in to preserve deterministic stateless mocks
- The issue says no performance or compatibility claim should be made without evidence
