## What it is

Microcks turns API and microservices assets such as OpenAPI, AsyncAPI, gRPC protobuf, GraphQL, Postman and SoapUI into live mocks and reuses them for contract and non-regression tests. For 2.0 the study keeps the API contract as source of truth, aims to keep the CLI API ideally compatible, preserves stateless deterministic mocks by default, and explores keeping MongoDB on a recent version and replacing Spring Boot with Quarkus.

## Risks

- Issue #2412 states nothing is decided unless explicitly stated, so 2.0 scope remains uncertain.
- MongoDB 4.4 is described as end-of-life, with 5.0 and 6.0 also described as end-of-life, requiring a version decision.
- The MongoDB SSPL licence and CNCF position are listed as to be confirmed, not settled.
- A PostgreSQL/JSONB alternative is described as a large rewrite and migration effort.
- The Spring Boot to Quarkus move is described as strong coupling concentrated in servlet mock processing, Mongo persistence, and security, so it is not purely mechanical.

## Open questions

- What is the CNCF position on the SSPL?
- What upgrade notes will be provided for 4.4 users?
- Whether DocumentDB will be used as an alternative during development to avoid licensing or distribution issues remains unconfirmed.
